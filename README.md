# Interview Knowledge Graph

A Neo4j-based interview analytics system that models candidates, applications,
roles, interview rounds, questions, skills, answers, and feedback as an
interconnected knowledge graph.

## Features

- Graph-based interview data modeling
- Candidate and application management
- Interview performance analysis
- Skill-based analysis
- Recruiter-oriented Cypher queries
- CRUD operations
- Aggregation and graph traversal
- Python and Neo4j integration

## Tech Stack

- Python
- Neo4j
- Cypher
- Pandas
- Neo4j Python Driver
